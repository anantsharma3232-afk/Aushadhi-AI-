# Aushadhi AI - Voice Healthcare Agent for Alexa+

An intelligent voice-first healthcare agent built for the Amazon Alexa+ Hackathon. It helps users find affordable Jan Aushadhi generic alternatives for branded medicines, providing dosage timing and clinical safety warnings.

## 🚀 Features
- **Voice-First Medicine Search:** Ask Alexa for any branded medicine to find its low-cost generic alternative.
- **Jan Aushadhi Integration:** Maps salt compositions to affordable government-approved Jan Aushadhi medicines.
- **Dosage & Clinical Guidelines:** Provides clear dosage timing and crucial safety warnings.
